# 🚀 VOXA - Realtime Order Display System

نظام شاشات عرض الطلبات اللحظي المخصص للكافيهات والمطاعم، يعتمد على تحديث البيانات الفوري بدون الحاجة لإعادة تحميل الصفحة.

## 🛠️ التقنيات المستخدمة (Tech Stack)
- **Frontend:** HTML5, CSS3, JavaScript (ES6)
- **Backend / Database:** Firebase Realtime Database
- **Hosting:** Vercel / GitHub Pages

## ✨ المميزات
- تحديث لحظي فور تغير حالة الطلب (قيد التحضير ➔ جاهز للاستلام).
